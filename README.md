Небольшая тестовая прошивка на C для **PIC16F628A**: периодически отправляет счётчик через аппаратный USART и переключает три цифровых выхода. Такой сценарий удобен при первичном запуске платы и проверке связи с USB–UART адаптером или логическим анализатором.

## Что делает код

```mermaid
flowchart LR
    A[Внутренний генератор 4 МГц] --> B[PIC16F628A]
    B --> C[USART TX · RB2 · 19 200 бод]
    B --> D[GPIO · RA2 / RA0 / RA1]
    C --> E[Терминал / логический анализатор]
```

| Параметр | Значение в исходнике |
|---|---|
| MCU | PIC16F628A |
| Среда | MPLAB X, XC8 2.45; device pack PIC16Fxxx_DFP 1.4.149 |
| Тактирование | Внутренний генератор, `_XTAL_FREQ = 4000000` |
| USART | Асинхронная передача, 8 бит, `BRGH=1`, `SPBRG=12` |
| Скорость | Номинально 19 200 бод; расчётно 19 230,8 бод (+0,16%) |
| Вывод TX | RB2; RB1 настроен как вход RX, обработка приёма не реализована |
| Выходы | RA2, RA0, RA1 |
| Цикл | Значения 0…255, задержка 500 мс плюс время отправки строки |

Ожидаемый вывод терминала (пример по коду, не записанный лог измерения):

```text
PICstring000
PICstring001
PICstring002
...
PICstring255
PICstring000
```

Последовательность GPIO определяется `i % 5`:

| Остаток | RA2 | RA0 | RA1 |
|---:|---:|---:|---:|
| 0 | 1 | 0 | 0 |
| 1 | 1 | 1 | 0 |
| 2 | 1 | 1 | 1 |
| 3 | 0 | 1 | 1 |
| 4 | 0 | 0 | 1 |

## Сборка и проверка

1. Скачайте репозиторий целиком (или распакуйте [PIC16_test.X-source.zip](PIC16_test.X-source.zip)), при необходимости переименуйте корневую папку в `PIC16_test.X` и откройте её через **File → Open Project** в MPLAB X.
2. Выберите PIC16F628A, XC8 и подключённый программатор. Версии исходной конфигурации указаны выше; локальные пути IDE и логи из архива исключены.
3. Выполните **Clean and Build**, затем прошейте микроконтроллер. В конфигурации `LVP=OFF`, поэтому нужен поддерживаемый программатором режим программирования через MCLR/VPP.
4. Соедините RB2/TX с RX адаптера согласованного логического уровня и объедините GND. Терминал: **19200, 8N1**, без управления потоком.
5. Проверьте счётчик и состояния RA2/RA0/RA1. При подключении светодиодов используйте токоограничивающие резисторы.

## Состав и статус

[main.c](main.c), `Makefile` и каталог `nbproject/` образуют проект MPLAB X и доступны непосредственно на GitHub. ZIP дублирует исходную структуру для удобного скачивания. Схемы и разводки PCB в переданном каталоге этого проекта нет. Выполнен статический разбор исходника; повторная сборка XC8 и проверка на физической плате при подготовке портфолио не выполнялись.
